# 任平生

萬鈞伯裘中史科成長遊戲。

**歷千年風雨，成就我人生。**

每個登入帳號是獨立角色（男女路線），答對題目與完成小遊戲可升級，從奴隸／婢女走到皇帝／女皇。

## 長卷互動關

主線八章的互動關分開手感（同一種最多兩章；而家每章一種）：

| 章 | 互動 |
| --- | --- |
| 第一章　啟程之路 | 配對（機緣連線・制度與含義） |
| 第二章　人物識名 | 古人問答 |
| 第三章　事件與時序 | 時光長河 |
| 第四章　因果初探 | 因果連結 |
| 第五章　政策與民生 | 成效與代價 |
| 第六章　史料會讀 | 史料對質 |
| 第七章　跨章綜合 | 路線抉擇 |
| 第八章　登基預備 | 限時朝議 |

配對題池用現有 `ww3`。問答同「時光長河」沿用原來的小遊戲。其餘四種在章內完成，過關仍寫入長卷進度同經驗。

| --- | --- |

| 中一・2　秦漢 | 機緣連線 → 因果連結 → 時光長河 → 遺物拼圖 → 錯史之戰 |
| 中一・3　三國兩晉南北朝 | 路線抉擇 → 遺物拼圖 → 時光長河 → 機緣連線 |
| 中一・4　隋唐 | 時光長河 → 遺物拼圖 → 機緣連線 → 限時朝議 → 錯史之戰 |
| 中二・1　宋元 | 因果連結 → 時光長河 → 機緣連線 → 遺物拼圖 → 錯史之戰 |
| 中二・2　明 | 時光長河 → 機緣連線 → 路線抉擇 → 錯史之戰 → 遺物拼圖 |
| 中二・3　清 | 遺物拼圖 → 機緣連線 → 時光長河 → 史料對質 → 錯史之戰 |
| 中三・1　中華民國 | 古人問答 → 限時朝議 → 時光長河 → 機緣連線 → 遺物拼圖 |

因果連結、成效與代價、史料對質、路線抉擇、限時朝議沿用長卷的互動板，題目按單元另寫。遺物拼圖要自己決定邊幾塊碎片先嵌合。呢兩關答錯可以再試，唔扣三盞燈火，亦唔另加經驗；闖關成功仍然是原來的單元獎勵。時光長河同機緣連線的經驗照舊。

試一個單元：用本機伺服器開頁，註冊一個**唔係現場學生**的測試學號（唔好用 `3A40`），年級揀中一。首頁「單元闖關」→ 中一單元 3 →「闖關」。順序是路線抉擇、遺物拼圖、時光長河、機緣連線。四關過完會見到「闖關成功」。

## 航程

首頁「玩」入面「上路」。新帳號會先見到阿禾的求援信，可揀「我先沿原來的路走」，再拖左下圓鈕沿 3D 商隊路線走。

早段仍係課堂入門（辨傳聞、三朝次序、西周分封）。由河邊起改為事件卡：商隊帶著糧、絲、錢、民力，要花資源或冒一個寫明的險，先見到歷史後果。時代對不上的選項不扣資源，也不能過站。每張卡都有一個不必先扣資源的做法，資源見底仍可走完。七雄方位、同窗布旗、求援信同會盟草案維持原樣。城樓第一次收下仍加經驗。

| 站 | 類型 |
| --- | --- |
| 城門 | 上路引導 |
| 市集／山路 | 課堂入門：辨傳聞／三朝次序 |
| 城樓 | 收下地盤（經驗） |
| 營帳 | 課堂入門：西周分封 |
| 河邊 | 事件卡・風險（黃河水勢／山溪。經山路或再走一程換卡） |
| 松山 | 事件卡・貨殖（以絲換路／關市） |
| 七雄 | 方位配對（保留） |
| 海岸 | 事件卡・路線（下西洋或留岸／官船或夜航） |
| 樓閣 | 事件卡・貨殖（書同文／度量衡） |
| 渡口 | 事件卡・風險（徵發換糧／河工） |
| 關城 | 事件卡・後果（開封入城／開封市結算） |
| 同窗 | 合作謎題（保留） |

試全段：本機伺服器開頁，註冊一個**唔係現場學生**的測試學號（唔好用 `3A40`）。跳過求援信後，由城門走到關城。河邊應見到資源同三個做法，揀完先出現「這一站的後果」。關城結算會列出資源。再走一程會換另一組事件卡。

## 功能

- **註冊／登入**：本機 `localStorage` 存帳號進度（適合課堂／家用；不同瀏覽器資料不互通）
- **題目練習**：選擇題、填充題、配對題（中一至中三，中等難度）
- **小遊戲**：Wordwall 風格翻牌／問答、人物時間線、與古人對話、史戰風雲
- **影片區**：可嵌入 YouTube 教育影片（於 `js/data/videos.js` 設定）

題目依香港初中中史課程主題**自擬**，對齊齡記／亮點中國史常見單元，並非直接複製出版社課文或工作紙原文。

## 本機預覽

因使用 ES modules，請用本機伺服器開啟（勿直接雙擊 `index.html`）：

```bash
cd "萬鈞伯裘-皇朝之路"
python3 -m http.server 8080
```

瀏覽器打開：http://localhost:8080
