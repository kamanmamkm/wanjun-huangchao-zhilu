# 任平生

萬鈞伯裘中史科成長遊戲。

**歷千年風雨，成就我人生。**

每個登入帳號是獨立角色（男女路線），答對題目與完成小遊戲可升級，從奴隸／婢女走到皇帝／女皇。

## 長卷互動關

主線八章的互動關分開手感（同一種最多兩章；而家每章一種）：

| 章 | 互動 |
| --- | --- |
| 第一章　啟程之路 | 配對（機緣連線・制度與含義） |
| 第二章　人物識名 | 古人問答 |
| 第三章　事件與時序 | 時光長河 |
| 第四章　因果初探 | 因果連結 |
| 第五章　政策與民生 | 成效與代價 |
| 第六章　史料會讀 | 史料對質 |
| 第七章　跨章綜合 | 路線抉擇 |
| 第八章　登基預備 | 限時朝議 |

配對題池用現有 `ww3`。問答同「時光長河」沿用原來的小遊戲。其餘四種在章內完成，過關仍寫入長卷進度同經驗。

試一個單元：用本機伺服器開頁，註冊一個**唔係現場學生**的測試學號（唔好用 `3A40`），年級揀中一。首頁「單元闖關」→ 中一單元 3 →「闖關」。順序是路線抉擇、遺物拼圖、時光長河、機緣連線。四關過完會見到「闖關成功」。

## 中三深讀

中三由兩個單元加到四個，順序是民國、抗戰、共和國、當代。共和國那一關的存檔編號仍是 `s3u2`，畫面上的單元號碼改為 3，舊進度留在這一關。中一、中二的闖關順序沒有改。

民國補了錯史「三民被併錯」。共和國補了鄧小平問答，自選還可打「開放被寫成閉關」。抗戰和當代是新關，各有時序、配對、互動板、遺物，以及錯史或問答。

查案在安史之外加了四則，都是中三先見到，玩法和經驗同安史一樣（首次完成 +12，重玩不加）：

| 查案 | 要分開的說法 |
| --- | --- |
| 簡報把兩年併成一年 | 九一八不是全面抗戰的開始 |
| 三民被寫成另一套 | 三民不是三大政策，也不是建國程序 |
| 開放被寫成閉關 | 改革開放不是 1949 年的閉關 |
| 回歸被寫成同一年 | 香港 1997、澳門 1999 |

探究加了兩題，同樣是先查改過的字，再判斷，再決定怎樣處理。第一次結案 +8，舊的「榜上多了一行」仍然在。

- 簡報多了一行（九一八／七七）
- 通告併了兩個年份（1997／1999）

試一個中三單元：同一類測試學號，年級揀中三。首頁「單元闖關」→ 中三 → 單元 2　抗日戰爭 →「闖關」。順序是時光長河、因果連結、遺物拼圖、機緣連線、錯史之戰。五關過完會見到「闖關成功」。

試一則新查案：中三學號登入，打開首頁「行囊與說明」，入面有「簡報把兩年併成一年」。撳「查案」→「開始調查」，標出把 1937 年收走的句子，點開線索後揀「線索②　七七事變與全面抗戰」，再揀一種處理。結案會寫「經驗 +12」。再查一次不會再加。

## 功能

- **註冊／登入**：本機 `localStorage` 存帳號進度（適合課堂／家用；不同瀏覽器資料不互通）
- **題目練習**：選擇題、填充題、配對題（中一至中三，中等難度）
- **小遊戲**：Wordwall 風格翻牌／問答、人物時間線、與古人對話、史戰風雲
- **影片區**：可嵌入 YouTube 教育影片（於 `js/data/videos.js` 設定）

題目依香港初中中史課程主題**自擬**，對齊齡記／亮點中國史常見單元，並非直接複製出版社課文或工作紙原文。

## 本機預覽

因使用 ES modules，請用本機伺服器開啟（勿直接雙擊 `index.html`）：

```bash
cd "萬鈞伯裘-皇朝之路"
python3 -m http.server 8080
```

瀏覽器打開：http://localhost:8080
